- Obtain ToxiCN-MM through the [official ToxiCN-MM repository and request instructions](https://github.com/DUT-lujunyu/ToxiCN_MM).

## Code-only public repository

The public repository contains code, configuration files, tests built from synthetic values, and reproduction documentation. It does not contain:

- raw or transformed dataset content;
- source sample keys;
- model input manifests;
- model predictions or raw responses;
- labels or per-sample correctness records;
- aggregate metrics, statistical tables, or paper-result summaries; or
- credentials, private annotation records, or local filesystem paths.

The following paths are ignored and are intended only for authorized local work:

```text
data/private/
data/manifests/
data/pvd/
predictions/
outputs/
checkpoints/
```

Before pushing a commit, run `git status --short` and confirm that none of these materials is staged.
